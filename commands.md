# Git and GitHub 15 Commands Assignment

This document contains 15 essential Git commands with their descriptions.

1. **git init**
   - Description: Initializes a new, empty Git repository in your local project folder.

2. **git clone <url>**
   - Description: Copies an existing remote repository from GitHub to your local computer.

3. **git status**
   - Description: Checks the current state of your working directory and staging area (shows modified or untracked files).

4. **git add <file>**
   - Description: Adds changes from your working directory to the staging area to prepare them for a commit.

5. **git commit -m "message"**
   - Description: Saves the staged changes permanently into the local repository history with a descriptive message.

6. **git log**
   - Description: Displays the chronological commit history of the repository.

7. **git branch**
   - Description: Lists, creates, or deletes branches in your repository.

8. **git checkout <branch-name>** (or **git switch**)
   - Description: Switches between different branches in your project.

9. **git merge <branch-name>**
   - Description: Combines changes from a specified branch into your current active branch.

10. **git remote add origin <url>**
    - Description: Connects your local repository to a remote repository hosted on GitHub.

11. **git push -u origin main**
    - Description: Uploads your local commits up to the remote repository on GitHub.

12. **git pull**
    - Description: Fetches and merges changes from the remote GitHub repository into your local machine.

13. **git fetch**
    - Description: Downloads updates and new branches from the remote repository without merging them automatically.

14. **git diff**
    - Description: Shows the exact line-by-line differences and changes made in your files before staging.

15. **git rm <file>**
    - Description: Removes files from your working directory and stages the deletion for the next commit.
